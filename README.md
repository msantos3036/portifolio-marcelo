# 💼 Portfólio Profissional | Marcelo Santos

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte do desafio da DIO com o objetivo de criar um portfólio front-end do zero.

O portfólio apresenta minha trajetória profissional, competências e projetos, conectando minha experiência em controladoria, finanças e análise de dados com minha evolução na área de tecnologia.

---

## 🚀 Objetivo

Criar uma página moderna, responsiva e organizada que represente minha identidade profissional e sirva como vitrine para projetos e habilidades técnicas.

---

## 🧠 Sobre mim

Sou um profissional com mais de 30 anos de experiência em:

- Controladoria
- Planejamento financeiro
- Análise de resultados
- Indicadores gerenciais

Atualmente, estou expandindo minha atuação para tecnologia e dados, desenvolvendo projetos práticos em:

- HTML, CSS e JavaScript
- Python
- Go (Golang)
- MySQL
- Power BI

Meu foco é integrar finanças, dados e tecnologia para gerar eficiência e apoiar decisões estratégicas.
